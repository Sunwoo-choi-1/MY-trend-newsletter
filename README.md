# 🐥💻 나만의 트렌드 뉴스레터 스킬

컴퓨터를 꺼도 매일 원하는 시간에, 나한테 맞춘 트렌드 뉴스가 예쁜 메일로 와요.
5~7분이면 다 읽는 분량이에요.
만든 사람: AI로다했서누

## 디자인 3종

| 디자인 | 느낌 |
|---|---|
| `basic` | 크림 배경에 코랄 포인트, 노트북으로 일하는 병아리가 반겨줘요 (기본) |
| `dark` | 검정 배경에 오렌지 포인트, 시크하게 |
| `trendy` | 형광 라임에 굵은 테두리, 힙하게 |

지시문에 `디자인: dark`처럼 적으면 돼요. 안 적으면 basic으로 와요.
바꾸고 싶으면 그 한 줄만 고치면 돼요. 스킬은 다시 올릴 필요 없어요.

## 뉴스레터에 들어가는 것

1. **3줄 요약** : 바쁘면 이것만
2. **딥다이브** : 오늘 가장 중요한 소식 하나를 깊게, 그래프 포함 (있는 날만)
3. **트렌드 브리핑** : 내가 뉴스레터로 얻고 싶은 것에 맞춰 찾은 소식 + "그래서 나는?"
4. **키워드 레이더** : 오르는 말, 내려가는 말 (있는 날만)
5. **✨ 요즘트렌드** : 9년차 마케터가 매일 보는 트렌드 미디어에서 골라온 글 (매일 고정)
6. **오늘의 액션** : 오늘 딱 하나만 해볼 것
7. **참고한 자료** : 이번 메일에 쓴 모든 출처

- 모든 소식은 **최근 5일 안**에 올라온 글만 담아요.
- 기사와 글의 **대표 이미지**를 원문에서 함께 가져와요.
- 인사말은 **메일을 받는 시간**에 맞춰요. 따로 적지 않아도 예약 작업이 실행된 시각을 보고 알아서 맞춰요. 아침엔 "좋은 아침", 저녁엔 "오늘 하루 수고 많았어요"처럼요.

## 준비물
- 클로드 유료 구독
- Gmail 커넥터 연결

## 1. 스킬 올리기
받은 ZIP 파일을 **압축 풀지 말고 그대로** 클로드 설정의 스킬 메뉴에 업로드하세요.

> 압축을 풀었다가 다시 묶으면 "SKILL.md must be in the top-level folder" 에러가 나요.
> 다시 묶어야 한다면, 폴더째가 아니라 안에 든 **SKILL.md, settings.md, README.md, assets를 골라서** 압축하세요.

## 2. 예약 작업 만들기
아래를 복사해서 내 정보로 바꾼 뒤, 예약 작업 지시문에 붙여넣으세요.

**예시 1. 카페 사장님**
```
trend-newsletter 스킬을 사용해서 오늘의 트렌드 뉴스레터를 만들고, 아래 설정대로 Gmail로 보내줘.
디자인: basic
이름: 지민
직업: 제주에서 카페 운영
뉴스레터로 얻고 싶은 것: 다음 달 신메뉴로 뭘 낼지 정하고 싶어. 요즘 뜨는 디저트와 음료, 관광객이 카페를 고르는 기준이 어떻게 바뀌는지 알고 싶어.
Gmail 주소: 내메일@gmail.com
```

**예시 2. 마케터**
```
trend-newsletter 스킬을 사용해서 오늘의 트렌드 뉴스레터를 만들고, 아래 설정대로 Gmail로 보내줘.
디자인: dark
이름: 수진
직업: 인하우스 퍼포먼스 마케터
뉴스레터로 얻고 싶은 것: 이번 주 광고 소재 아이디어. 메타·유튜브 광고의 새 기능, 반응 좋은 숏폼 광고 포맷, 실무에 바로 쓸 AI 마케팅 툴 소식.
Gmail 주소: 내메일@gmail.com
```

**예시 3. 육아**
```
trend-newsletter 스킬을 사용해서 오늘의 트렌드 뉴스레터를 만들고, 아래 설정대로 Gmail로 보내줘.
디자인: basic
이름: 하나
직업: 5살 아이 키우는 엄마
뉴스레터로 얻고 싶은 것: 주말에 아이랑 뭐 하고 놀지 고르고 싶어. 요즘 부모들이 많이 가는 키즈 체험, 인기 놀이와 교구, 새로 생긴 육아 지원 소식.
Gmail 주소: 내메일@gmail.com
```

### 지시문 쓰는 팁
- **첫 줄은 지우지 마세요.** `trend-newsletter 스킬을 사용해서 오늘의 트렌드 뉴스레터를 만들고, 아래 설정대로 Gmail로 보내줘.` 이 줄이 있어야 예약 작업이 매번 이 스킬로 뉴스레터를 만들어요.
- **직업**은 일이 아니어도 돼요. "육아 중인 엄마", "투자 공부하는 직장인"처럼 나를 설명하는 말이면 돼요.
- **뉴스레터로 얻고 싶은 것**이 가장 중요해요. 키워드만 나열하기보다 **"이 뉴스레터를 읽고 무엇을 하고 싶은지"**를 문장으로 써주세요.
  - 아쉬운 예: `카페, 디저트, 제주`
  - 좋은 예: `다음 달 신메뉴를 정하고 싶어. 요즘 뜨는 디저트랑 관광객이 카페 고르는 기준이 궁금해.`
  - 이렇게 쓰면 "그래서 나는?"과 "오늘의 액션"도 그 목적에 맞춰 나와요.
  - 연예, 정치, 사건사고 소식도 받을 수 있어요. 궁금하면 뉴스레터로 얻고 싶은 것에 적어주세요. (예: `요즘 화제인 드라마랑 연예 이슈도 알고 싶어`)
- **컴퓨터가 꺼져도 오게 하려면:** 클라우드에서 실행되는지 확인하세요. "이 컴퓨터 필요" 같은 옵션이 있다면 꺼주세요. 화면은 업데이트에 따라 조금 다를 수 있어요.

## 3. 테스트

메일이 안 오면 실행 기록을 열어서 어디서 멈췄는지 확인하세요.

## 자주 묻는 것
- **Gmail 주소를 안 적었어요** → 안전을 위해 메일을 보내지 않고 멈춰요.
- **딥다이브, 키워드 레이더가 없는 날이 있어요** → 그날 출처가 확실한 자료가 없으면 일부러 빼요. 지어낸 내용을 넣지 않기 위해서예요.
- **요즘트렌드 매체에 새 글이 없으면요?** → 기본 매체 4곳(고구마팜, 캐릿, 디에디트, 큐레터)에 5일 안의 새 글이 없으면 대체 매체 4곳(디지털 인사이트, 오픈애즈, 대학내일20대연구소, 브랜드브리프)에서 찾고, 그래도 없으면 내 분야의 트렌드 리포트를 검색해서 채워요.
- **기사 이미지가 안 보여요** → 매체 사정으로 이미지가 막히는 날이 있어요. 원문 링크로 보시면 돼요. 쓸 만한 이미지가 없는 기사는 이미지 없이 와요.
- **설정을 바꾸고 싶어요** → 예약 작업 지시문만 고치면 돼요. 스킬은 다시 올릴 필요 없어요.
- **맨 아래 크레딧을 빼고 싶어요** → 지시문에 "크레딧 빼줘" 한 줄을 추가하세요.
- **dark 디자인이 하얗게 보여요** → 일부 메일 앱은 다크 디자인 색을 바꿔서 보여줘요.
- **글씨체가 미리보기랑 달라요** → 메일 앱의 기본 글꼴로 보여줘요. 정상이에요.

## 주의
- 출처를 모르는 스킬은 함부로 올리지 마세요. 스킬은 클로드에게 일을 시키는 지시서예요.
- 기사 이미지는 원문 주소로만 불러오고 출처를 표시해요. 받은 메일을 캡처해서 다른 곳에 올릴 땐 이미지 출처를 꼭 남겨주세요.
